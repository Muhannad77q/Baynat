# بَيّنات — سؤال اليوم

تطبيق عربي تفاعلي يساعد المشرف على:

- إضافة الطلاب مع الاسم والصف ورمز دخول من أربعة أرقام.
- إنشاء سؤال يومي من نوع اختيار متعدد، صح أو خطأ، أو إجابة قصيرة.
- مشاركة رابط السؤال مع الطلاب.
- احتساب النقاط حسب صحة الإجابة وسرعة الحل وترتيب الطالب.
- عرض لوحة المتصدرين فور إرسال الإجابة.

## كيف يعمل الرابط المنفصل؟

لوحة المشرف تعمل في `/`، بينما يفتح الطالب رابطًا مستقلًا مثل:

```text
https://example.com/student.html?q=AbCd1234
```

الطالب يفتح الرابط من أي جوال، ويكتب اسمه وصفّه كما سجّلهما المشرف ثم رمزه ذي الأربعة أرقام. لا يظهر نص السؤال إلا بعد نجاح الدخول وبدء مؤقت الخادم. يبقى الجواب الصحيح والرموز داخل الخادم، وتصل الإجابة إلى لوحة المشرف وتظهر في ترتيب جميع الأجهزة تلقائيًا.

عند تشغيل الخادم أول مرة، يظهر `Baynat supervisor setup key` في سجل التشغيل. أدخله مرة واحدة في لوحة المشرف، ثم اختر رمز مشرف من ٦ خانات على الأقل. يمكن تحديد مفتاح معروف مسبقًا عبر `BAYNAT_SETUP_KEY`. هذا الرمز خاص بالمشرف ويحمي إنشاء الأسئلة؛ الطلاب لا يرونه ولا يحتاجون إليه.

## التشغيل

```bash
npm run dev
```

ثم افتح `http://localhost:5173`. ينشئ الخادم ملف البيانات الخاص به داخل `.data/`.

للتجربة من جوال آخر على الشبكة نفسها، افتح عنوان الجهاز بدل `localhost`، ثم انسخ رابط الطالب من لوحة المشرف وأرسله إلى الجوال.

## الاختبارات

```bash
npm test
```

تشمل الاختبارات إنشاء سؤال من جلسة المشرف، ودخول أكثر من طالب من جلسات مستقلة، وإرسال الإجابات، وترتيب النتائج، واستعادة البيانات بعد إعادة تشغيل الخادم.

## النشر

التطبيق أصبح خدمة Node.js كاملة، وليس موقع GitHub Pages ثابتًا. شغّله باستخدام `npm start` على استضافة تدعم Node.js وقرصًا دائمًا، واضبط `PORT` عند الحاجة. صورة Docker تحفظ البيانات في `/data`.

- شغّل عملية Node واحدة لكل ملف بيانات؛ يمنع ملف القفل تشغيل عمليتين حتى لا تضيع الإجابات. بعد توقف غير طبيعي فقط، تأكد أن كل العمليات متوقفة قبل حذف ملف `.lock` يدويًا.
- لا تضبط `TRUST_PROXY=true` إلا خلف وكيل موثوق يحذف ترويسة `X-Forwarded-For` الواردة من المستخدم ويكتبها بنفسه.
- يتحقق المتصفح تلقائيًا من كل محاولة دخول قبل فحص الاسم والصف والرمز، ولا يمكن إعادة استخدام التحقق نفسه. القيمة الافتراضية لـ `BAYNAT_ACCESS_DIFFICULTY` هي `20` ولا يقبل الإنتاج قيمة أقل منها.
- إذا كثرت محاولات دخول المشرف من الشبكة نفسها، ينفّذ المتصفح تحققًا إضافيًا تلقائيًا بدل حظر المشرف مع بقية مستخدمي الشبكة. يمكن ضبط صعوبته عبر `BAYNAT_SUPERVISOR_DIFFICULTY`، وقيمته الافتراضية `16`.
- تنتهي غرف الأسئلة بعد ٣١ يومًا وتُحذف المنتهية عند إنشاء سؤال جديد.
- استخدم HTTPS في النشر الفعلي، وخذ نسخة احتياطية دورية من ملف البيانات.
