# بينات

بوابة عربية متجاوبة لإدارة حلقات القرآن، مع تجربة مستقلة لكل من:

- المعلّم: الحضور، الحفظ، التلاوة، المراجعة، التثبيت، والتفسير المختصر.
- ولي الأمر: متابعة تقدّم الابن وواجباته ورسائل المعلّم.
- الطالب: خطة التسميع والواجبات اليومية والإنجازات.
- المشرف: إدارة الطلاب والمشرفين والمعلّمين والتقارير.

## التشغيل

```bash
npm run dev
```

يفتح الموقع على `http://localhost:5173`.

## حسابات التجربة

كلمة المرور لكل الحسابات: `123456`

| الدور | اسم المستخدم |
| --- | --- |
| معلّم | `teacher` |
| ولي أمر | `parent` |
| طالب | `student` |
| مشرف | `supervisor` |

> تسجيل الدخول والبيانات الحالية تحفظ محليًا في المتصفح لأغراض العرض. يلزم backend آمن قبل استخدامها في بيئة فعلية.
