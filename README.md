# بَيّنات — سؤال اليوم

تطبيق عربي تفاعلي يساعد المشرف على:

- إضافة الطلاب مع الاسم والصف ورمز دخول من أربعة أرقام.
- إنشاء سؤال يومي من نوع اختيار متعدد، صح أو خطأ، أو إجابة قصيرة.
- مشاركة رابط السؤال مع الطلاب.
- احتساب النقاط حسب صحة الإجابة وسرعة الحل وترتيب الطالب.
- عرض لوحة المتصدرين فور إرسال الإجابة.

## التشغيل

```bash
npm run dev
```

ثم افتح `http://localhost:5173`. رمز الطالب التجريبي هو `4821`.

## الاختبارات

```bash
npm test
```

النسخة الحالية تعمل بالكامل في المتصفح وتحفظ البيانات في `localStorage`. رابط المشاركة يتضمن السؤال وقائمة الطلاب بصورة مناسبة للنموذج التجريبي، لكن مزامنة النتائج بين أجهزة متعددة تحتاج ربط واجهة خلفية وقاعدة بيانات قبل الإطلاق الفعلي.
