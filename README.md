# بَيّنات — سؤال اليوم

تطبيق عربي تفاعلي يساعد المشرف على:

- إضافة الطلاب مع الاسم والصف ورمز دخول من أربعة أرقام.
- إنشاء سؤال يومي من نوع اختيار متعدد، صح أو خطأ، أو إجابة قصيرة.
- مشاركة رابط السؤال مع الطلاب.
- احتساب النقاط حسب صحة الإجابة وسرعة الحل وترتيب الطالب.
- عرض لوحة المتصدرين فور إرسال الإجابة.

## كيف يعمل الرابط المنفصل؟

لوحة المشرف تعمل في `/`، بينما يفتح الطالب رابطًا مستقلًا مثل:

```text
https://example.com/student.html?q=AbCd1234
```

الطالب يفتح الرابط من أي جوال، ويدخل رمزه فقط. يبقى السؤال الصحيح ورموز الطلاب داخل الخادم، وتصل الإجابة إلى لوحة المشرف وتظهر في ترتيب جميع الأجهزة تلقائيًا.

## التشغيل

```bash
npm run dev
```

ثم افتح `http://localhost:5173`. ينشئ الخادم ملف البيانات الخاص به داخل `.data/`.

للتجربة من جوال آخر على الشبكة نفسها، افتح عنوان الجهاز بدل `localhost`، ثم انسخ رابط الطالب من لوحة المشرف وأرسله إلى الجوال.

## الاختبارات

```bash
npm test
```

تشمل الاختبارات إنشاء سؤال من جلسة المشرف، ودخول أكثر من طالب من جلسات مستقلة، وإرسال الإجابات، وترتيب النتائج، واستعادة البيانات بعد إعادة تشغيل الخادم.

## النشر

التطبيق أصبح خدمة Node.js كاملة، وليس موقع GitHub Pages ثابتًا. شغّله باستخدام `npm start` على استضافة تدعم Node.js وقرصًا دائمًا، واضبط `PORT` عند الحاجة. يجب استخدام HTTPS في النشر الفعلي.
